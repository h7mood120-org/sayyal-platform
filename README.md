# سيّال | Sayyal — Hackathon Prototype

طبقة سوق ثانوي للاستثمارات غير السائلة الموجودة عبر منصات التمويل الجماعي بالدين.
نموذج تجريبي (Prototype) لأغراض **VentureX** — وليس منتجًا إنتاجيًا.

---

## التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
```

للإنتاج:

```bash
npm run build && npm run start
```

لا يحتاج المشروع إلى أي API keys أو Backend. كل شيء يعمل محليًا عبر mock data و local state.

## سيناريو العرض أمام لجنة التحكيم

1. افتح التطبيق — ستكون على حساب **محمد العتيبي** (البائع).
2. الرئيسية: محفظة بقيمة **124,850 ر.س** موزعة على **صكوك / أصيل / جياد**، منها **78,500 ر.س** متاحة للتخارج.
3. اضغط على **شركة مدار اللوجستية** (10,000 ر.س · 11.2% · متبقٍ 18 شهر).
4. من بطاقة السيولة الجانبية: **عرض الاستثمار للبيع**.
5. سعر العرض الافتراضي **9,700 ر.س** → خصم **3.0%** · عائد تقديري للمشتري **13.1%**.
6. **نشر العرض في سوق سيّال** → تظهر نافذة التأكيد.
7. من مبدّل وضع العرض في الأعلى، انتقل إلى **المشتري: سارة**.
8. **سوق سيّال** → عرض محمد يظهر أول القائمة بشارة «عرض جديد».
9. افتح الفرصة → **شراء بـ 9,700 ر.س**.
10. رصيد سارة 2,450 ر.س فقط → اختر **مصرف الراجحي** → محاكاة المصرفية المفتوحة → **تأكيد الشراء**.
11. تظهر مراحل التسوية الست، ومنها «طلب نقل الملكية — يتم التنفيذ عبر الجهة المرخصة».
12. **تمت الصفقة بنجاح** → محفظة سارة أصبحت 50,000 ر.س ويظهر فيها أصل مدار.
13. ارجع إلى **محمد**: رصيده 9,700 ر.س، ومركز مدار أصبح «تم التخارج».
14. افتح **ملخص العرض** (`/summary`) لشاشة الختام: «رأس المال لا يتوقف. ينتقل.»

زر **إعادة ضبط العرض التجريبي** في أسفل الشريط الجانبي يعيد كل شيء لحالته الأولى قبل كل عرض.

## البنية التقنية

- **Next.js 15** (App Router) + **TypeScript** + **Tailwind CSS**
- **Framer-free**: حركات CSS خفيفة بدل مكتبات ثقيلة، مع `prefers-reduced-motion`
- **lucide-react** للأيقونات
- خط **IBM Plex Sans Arabic** مستضاف ذاتيًا عبر `@fontsource` (يعمل دون إنترنت)
- RTL كامل، Dark mode افتراضي، أرقام جدولية (`tabular-nums`) مع عزل ثنائي الاتجاه

```
src/
  app/
    page.tsx                 الرئيسية / Dashboard
    portfolio/               محفظتي
    investment/[id]/         تفاصيل الاستثمار
    sell/[id]/               إنشاء عرض تخارج
    market/                  سوق سيّال
    market/[id]/             تفاصيل الفرصة (جانب المشتري)
    orders/                  أوامري

  components/
    Shell.tsx                Sidebar + Topbar + مبدّل الشخصيات + الإشعارات
    BuyFlow.tsx              الدفع + المصرفية المفتوحة + مراحل التسوية
    cards.tsx                بطاقات الاستثمار والفرص

```

### حساب العائد التقديري للمشتري

```
العائد التقديري = العائد الأصلي + (نسبة الخصم × 12 ÷ المدة المتبقية) × 0.95
```

معادلة مبسطة لأغراض العرض فقط، ولا تمثل حسابًا فعليًا لعائد الاستحقاق (YTM).
مثال مدار: `11.2 + (3.0 × 12 ÷ 18) × 0.95 = 13.1%`

## تنويه مهم

- **نموذج تجريبي لأغراض VentureX — لا تمثل المنصات الظاهرة شراكات فعلية مع سيّال.**
- أسماء **صكوك / أصيل / جياد** مستخدمة كأمثلة توضيحية على «المنصة الأصلية للاستثمار» فقط.
  لم يتسنَّ الحصول على شعاراتها الرسمية من مصدر عام موثوق أثناء بناء النموذج، لذلك استُخدمت
  **بطاقة نصية أنيقة** تحمل اسم المنصة كعنصر نائب — ولم يُخترع أي شعار ولم يُقدَّم على أنه رسمي.
  ملفات `public/platforms/*.svg` محجوزة لاستبدالها بالشعارات الرسمية عند توفرها.
- لا يُنسب إلى أي منصة حقيقية دعم السوق الثانوي أو تكامل قائم مع سيّال.
- جميع الشركات المصدرة، الأسعار، العوائد، المحافظ، الصفقات، الأرصدة والحسابات البنكية **بيانات تجريبية بالكامل**.
- لا يوجد تسجيل دخول حقيقي، ولا ربط فعلي بأي بنك أو مزود مصرفية مفتوحة.
- سيّال تُقدَّم كـ **technology / marketplace infrastructure layer**: لا تحتفظ بالأصل ولا تنقل
  الملكية بنفسها، بل تتكامل مع الجهات المرخصة التي تتولى التحقق ونقل الملكية والتسوية.
